# CLAUDE.md

`SPEC.md` is the single source of truth for the system (workflow, cover-letter
shape, implementation); `profile.md` holds the user's goal, positioning,
targeting, résumé style, and voice. Read them before doing anything here. This
file loads every session and carries only the non-negotiables.

- **The user writes the cover-letter prose.** The agent supplies facts and structure and proposes inline; only after the words are approved does the draft get saved, voice-linted, and rendered. Never draft-and-render before approval.
- **Use the name W.S. Gong** in résumé and cover-letter contexts.

## Trust boundary (never cross)

- **Never submit an application or fill a portal form.** Produce the PDFs; the user uploads them.
- **Never send an email or outreach message.** Draft only.
- **Never invent.** Every résumé line traces to `master-resume.md` or a base; every cover-letter fact to the JD or durable knowledge. If you can't source it, write `[NEEDS SOURCE: …]` and stop.

These hold in the batch flow too.
